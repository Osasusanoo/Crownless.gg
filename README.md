# Crownless.gg

A fan site for Wuthering Waves players and content creators that tracks Endgame stats in one place.

## Pages
- Home
- About
- Chart
- Team

## Built with
HTML, CSS, and Tailwind. Hosted on GitHub Pages.

## Data
Boss stats are kept in bosses.csv and converted to bosses-data.js by build_bosses.py.
